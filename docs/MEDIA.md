## 使用

桌面点顶栏扬声器，手机在「更多 → 声音与动画」打开面板。配乐、动作音效各有开关和音量，另有全部静音；可以试听打击或奖励音。新设置初次默认为配乐28%、音效70%，并在首次真实点击或按键后开启；浏览器未允许时显示提示，可点“恢复声音”。后台和离页暂停音频调度与环境动画，回到前台恢复当前场景，不补排过期节拍。浏览器不支持声音时游戏仍可继续，面板显示状态。

设置使用独立本机键ember-corridor.media.v1，包含music/effects/muted/musicVolume/effectsVolume/motion。不可保存时提示、当次仍生效。新媒体设置不迁移旧版默认关闭的sound，不把默认false误作用户在新面板中的选择；新面板保存后始终按其设置。旧v8 options.sound保留为当前音效开关与全部静音的兼容镜像，导入旧旅途不会覆盖本机媒体设置。音量和动效不随旅途JSON导出；换设备/入口后可重新设置。

每套八小节循环，配有四组和弦、持续铺底、拨弦式旋律、低音与按场景配置的轻打击；胜利使用较明亮的和声，各楼层变调。低通和短混响增加空间，场景层淡入/退出约0.8–0.95秒，不在每次重绘重启。旋律和噪声只使用媒体模块的独立常量/私有序列，不调用战斗或地图随机数。

AudioContext只在真实交互后创建/恢复。90ms调度器只预排约220ms、单次最多4步，不积压后台节拍；切到后台停止定时器、清理已排声音并暂停上下文，前台按当前场景重建。音源结束后断开并移出集合，场景旧层退出后清理；总音源上限72、音效28，最终总线统一压缩限幅。高密度输入按预算略过多余音源，不影响游戏动作。

## 动作音效

30个命名音色覆盖：UI、选牌、旋转、出牌、抽牌、斩击、重击、破甲、格挡、受伤、部位毁坏、护盾、包扎/治疗、强化剂、回合、敌方前摇、灼烧、出血、破裂、沉沦、震颤、徒步、折跃索、滑翔翼、金币、遗物、强化/科技、胜利、失败与错误。

使用纸牌噪声、短包络、扫频、低音冲击与多音金属/钟声组合；按实际扣层量、破甲、碎格、部位毁坏或动作结果分支播放。状态音效同次最多取两类，UI点击有75ms节流。合成参数只是声音选择，不修改伤害或奖励。技能的组合效果可能叠加数种声音，独立音量和静音始终生效。

## 动画

- 场景入场：地图/战斗淡入，已揭示节点依次显现；背景轻微呼吸、薄雾、当前位置与预览路线流动。
- 抽牌：根据真实UID识别新进入手牌的牌，仅新牌入场，选牌/重绘不反复重播整手动画。
- 地图移动：仍停留地图时，光点沿已有合法路线移动；装置跳跃采用其路线。进入房间/战斗时使用场景入场，不新增动作等待或确认。
- 战斗：保留原角色前摇、轨迹、削层、碎格、受击和护盾反馈，增加对应音色、机能/目标亮度反馈、回合提示和能量/科技微光。
- 弹窗：首次打开淡入，已有选牌/科技滚动与焦点保留，媒体滑块输入不重绘整页或重置焦点。
- 随系统/完整/轻量/关闭：默认随系统；轻量停止环境漂移、位移、摇晃和粒子，保留淡入/静态伤害文字；关闭时保留生命变化和静态结算提示。隐藏页面取消进行中的展示动画，环境CSS暂停。

装饰不拦截点击；攻击仍点格即出，Auto、弃牌/移动/移除/强化确认保持。音频与动效只读状态，原完整动作先结算和保存，再播放反馈，不用动画时长门控出牌或重置随机数。v8、路线7、永久科技及所有数值不变。
