# 手机专用HTML

需求user-2026-10-22-mobile-html，用户原话：“做一个专门适配手机端的html”。本轮代码与文档作者/执行者为Codex；没有DeepSeek或图像生成器调用，十项PNG保持原始字节。

## 文件与运行

- `dist/mobile.html`：独立手机页面结构，复用原五个模块和美术，加载mobile.css/mobile.js。
- `余烬回廊-手机版.html`：单文件离线版，内嵌两份样式、六个模块和十项PNG；传到手机，用支持本地HTML脚本的浏览器打开。文件管理器的静态预览不等同于浏览器运行。
- 电脑本机预览为 `http://127.0.0.1:4173/mobile.html`。现有服务仍仅绑定电脑的127.0.0.1；手机的127.0.0.1指向手机本身。本轮没有将服务开放到局域网或互联网。

tools/build-standalone.ps1默认同时生成桌面和手机版；可加 `-Edition desktop` 或 `-Edition mobile` 只合并一种。打包仅合并文本与图片，不执行游戏。独立手机版移除依赖其他文件的桌面入口；dist页面保留桌面链接。保留原始图片使两个离线文件各约39MB，没有引入压缩、远程字体、服务工作线程或运行依赖。

## 竖屏与触屏

顶部显示旅途站数和金币。战斗中央为独立可滚动区域：角色/身体摘要、敌人意图、6×4正方形生命格、预览及旋转/取消/AUTO。手牌横向滚动，固定宽度显示卡图和效果，避免挤成难点的小卡。能量、抽弃牌堆与结束回合固定在手牌下；底部是路线、身体、牌组、存档、更多。

点攻击牌后将生命格滚入视野，再点格子立即出牌；技能或AUTO点牌直接打出。滑动手牌、地图、房间、生命格或弹层超过12像素后，拦截该手势产生的点击，避免滚动时误出牌/选择；新触摸立即重新允许正常点击。没有增加出牌确认步骤。小屏可滚动战斗区域，主要操作和手牌保持在底部。

地图使用较长的画布与触屏节点，支持双向滑动；进入地图时定位下一站，战斗路线预览定位当前节点。路线和当前房间分别显示，商店/事件无需在窄侧栏阅读。身体详情使用大部位列表和双列能力，治疗操作位于弹层底部；连续选择伤处时保留滚动位置。

采用动态视口高度和安全区边距，保留浏览器缩放。横屏把战斗与手牌放在两侧；图片、弹层、触屏按钮、卡片和操作文字有专用规则。常用操作按钮至少44像素，地图密集节点为40像素。手机的战斗效果使用视口坐标，滚动战斗区域后仍向目标位置播放。

## 共用规则与存档

手机只改变展示和输入，沿用同一Battle、身体、Floor、牌库、数值、奖励及routeVersion规则。新增手机渲染/弹层事件、手牌横向滚动位置保留、手机提示与浮层坐标；展示事件不会出牌、发奖、修改存档或推进随机数。

HTTP同一站点的桌面和手机入口共用存储键；不同设备、网址、端口及文件地址的浏览器存储可能隔离，使用原有导出/导入迁移。不是云同步。切换前先导出或完成保存，目标页刷新后读取；不要同时在两个页面推进同一旅途，以免最后写入的进度覆盖前一页。既有JSON存档及手机导出的文件均用相同白名单校验恢复，不要求新开旅途。

## 审阅范围

主代理只审阅源码、页面入口、资源引用及差异，并执行离线合并。按用户要求没有运行游戏、语法检查、测试、设备模拟、浏览器自动化或手机试玩。不宣称已经过iOS/Android或具体屏幕尺寸验证；触感、可读性和实际浏览器打开效果由用户确认。所有文件在写入前纳入事务，前后快照留在本机，全部项目文件列入新PR。


## 五层旅途更新

手机与桌面同步为五层，完整内容见[FIVE-FLOORS.md](FIVE-FLOORS.md)。标题、地图、五层进度、首领结算、过层三选一和最终通关均复用共享状态；独立手机离线HTML同步更新。手牌/地图/房间定位键加入floorNumber，进入新层后重新定位；展示代码不推进随机数、不发放奖励。导出/导入与自动保存采用同一v3格式，可继续v1/v2第一层旧档并向上推进。源码审阅后静态打包，没有手机或浏览器测试。


## 多敌与弃牌确认

敌群以1–3个可点选的头像/生命/意图显示，当前目标有边框；生命格显示当前目标。多敌时收起重复的大目标画像，保留己方状态及独立敌人。超出9张的抽牌先进入待整理区，弹层两列显示原手牌和新牌，勾选后确认，确认按钮固定在底部并考虑安全区。未确认不弃牌，刷新恢复待整理与勾选。共享存档v4及新路线5规则见[MULTI-ENEMY-DRAW.md](MULTI-ENEMY-DRAW.md)。本轮仅源码审阅及静态合并，没有设备或浏览器测试。

## 选择效果、血条与卡牌强化（v5）

手机选择界面直接显示完整卡牌效果、费用及攻击形状，事件中的卡牌/遗物也展开说明。移除和营火强化使用两列选牌、明确选中态、强化前后对比及安全区底部确认/取消按钮；选中的卡牌内也展开强化后效果，长牌组可滚动。点选自动保存，确认前不收费或消耗节点，同名牌按单张分别处理。

血容量使用独立红条，盾徽带数字叠在条左边；身体合计生命另列。单敌/多敌的手机状态区为两条生命信息预留高度。手机和桌面共用v5存档及v1–v4迁移，未执行手机模拟、浏览器检查或游戏测试，实际触屏与视觉由用户检验。
