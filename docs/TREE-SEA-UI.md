## 视觉方向

参考[公开界面截图](https://www.taptap.cn/moment/828059228320039824)观察黑色半透明面板、冷青与雾紫氛围、环形节点和白色信息层级。截图仅用于观察，没有进入仓库；本作沿用原创图标、文字及玩法，不复制原作图片、标识或完整页面。

- 原创树海背景：暗色树干、冷青地雾、少量紫色天光；细节集中边缘，中央较暗。
- 地图：圆形节点徽记、外置标签、白色当前位置光环、冷青可达边框、浅色路线及淡紫装置路线；空地缩成圆点，当前空地仍保留旅人徽记。
- 顶栏与遗物：黑蓝半透明栏、淡色细边、横排原有独立图标；科技入口与剩余点数保持。
- 战斗：调查终端式身体、敌人生命格和意图面板；当前目标描边。九层生命格颜色、红色血容量条和护盾、伤势/状态语义保持。
- 卡牌：深蓝灰卡面、白色标题、青色数值、淡紫状态说明；选中、强化、不可支付仍各有状态。旧卡画仅降低饱和度，没有重新生成全套画像。
- 弹窗：选牌、移除、强化、弃牌确认、遗物、身体、存档和科技统一档案面板外观；费用/效果/确认规则保持。
- 手机版：同样外观，保留原竖屏布局、底部导航、安全区、滚动面板和地图预览；不更改触屏操作流程。
