# 五层与存档（v4）

当前旅途共五层，每层12站47节点，四种形状与种子决定的连接。第一层由种子从三种首领中选定一位，后四层各有专属首领。难度、内容及过层补给见[FIVE-FLOORS.md](FIVE-FLOORS.md)。

## 状态与跨层

状态仍为map、node、battle、reward、lost、cleared。前四层cleared表示当前首领已败，保留结算与过层补给入口；floorNumber=5且cleared才是整段通关。精英/首领在battle离开时一次入账金币及遗物，恢复结算不再发放。

选择补给后记入history、修复身体并给予35金币和下一层卡，floorNumber递增，生成独立路线，清空旧层当前节点/战斗/待领奖/购物/宝箱状态，进入map并立即保存。按钮重复点击时已不是cleared，不重复领取。牌组120张满时允许过层，跳过添加补给卡；普通奖励可跳过，事件/商店/营火学牌会拒绝超过上限。每层牌组、遗物、金币和剩余伤势延续。过层修复不重放首领奖品。

## 格式

顶层format为ember-corridor，version=4，包含savedAt、options、run。本地键仍为ember-corridor.save.v1，最近替换前备份加.backup；键名不等于数据版本。

run记录floorNumber（1–5）、history（长度恰为floorNumber-1）、seed、rngState、routeVersion、金币、牌组、遗物、visited、nodeId、screen、offers、bought、roomRelics、lastLoot。

history每项只保存白名单字段：floor（连续1起）、routeVersion、visited（完整首领路径）、boss（实际首领ID）、boon（assault/shelter/renewal）。导入重建对应层地图并逐边验证，首领必须与路径最后节点一致。最终层路径仍留在当前run.visited，前四层留在history。界面据此显示五层进度。

routeVersion=5表示分层敌群的新地图；4为之前分层单敌地图；几何仍沿用v3的12站47节点与四种走向，但地图种子首层为战役seed，后层为FNV派生seed+楼层，结果0改为1。地图种子可重建，不另信任导入字段。routeVersion=3是此前单层变化图；=2为固定十二站图，=1旧八站图。第二层起必须使用4或5，新过层使用5；第一层可保留任一旧版，history首层也允许旧版。

身体记录全部定义部位的HP/流血/缺失/父部位关系、格挡、血容量、强化和强化剂。部位上限从定义和残火之心重建，不信任导入对象。bandages=3仅兼容字段，包扎不限次数。再生通过清理缺失/连带来源并恢复一支部位树的实际生命执行，不改变部位定义和上限。

战斗保存enemies数组（每名24格0–9层生命/护甲、maxHp、力量、意图）、targetIndex，以及全局回合、能量、打牌数、小数余量、五个牌区UID和120条以内日志。pendingDraw保留超额新牌，overflowSelection保留未确认勾选。五区完整唯一覆盖牌组，确认前不移牌；具体见[MULTI-ENEMY-DRAW.md](MULTI-ENEMY-DRAW.md)。恢复时按节点所在层和路线版本重建敌群配置，验证maxHp和细胞总生命、护甲和卡牌完整唯一分区，构造不推进实际随机状态，并覆盖构造给予的开局格挡。每回合遗物格挡已包含在保存的hero.block中，不重复发放。

## v1 / v2 / v3迁移

v1/v2均视为第一层、history为空；v3保留原楼层及完整history，保留原routeVersion（v1为1）、种子、路线、当前节点、身体、牌组、遗物、商店购买与战斗。旧敌人、事件、奖励卡及商店遗物池的ID顺序在balance.js的legacy记录中冻结，避免新增内容改变旧地图、商品ID和当前敌人；旧12站图不会被新地图覆盖。旧首层cleared可直接选择补给继续第二层，v2/v3战利品保持原数值，不重新发放。

v1仍按既有规则校验旧生命，再按剩余比例削到较低首层上限，不复活空格，力量减半。若停在旧精英胜利/首领结算，补发一次未拥有遗物，原金币不重发。v2/v3不执行此补发。迁移成功先备份原始存档，再保存为v4，下次不重复迁移。

旧档在本层完成前保留旧图、旧商店和单敌；进入下一层后使用路线5的分层敌群。v4不能由旧版游戏读取，回到旧版前应保留原v1/v2/v3备份。

## 导入与保存边界

导入最多128KiB，只接受版本化JSON及白名单值，验证楼层、历史、种子、节点路径、状态、资源、遗物、部位、生命格及卡牌。失败不更改当前旅途，完整校验后才显示预览，确认后替换并备份；日志转义后展示，不执行导入文本。

每次完整动作、过层选择、节点选择与奖励领取后保存，敌人回合先同步结算再播放反馈。同源两页面可能共用存档，不应同时游玩；文件地址、端口、浏览器和设备可能隔离，需要导出/导入迁移。存储失败须显示失败状态，允许手动导出，不能冒称保存成功。游戏存档与代理审计独立。
