# 选择效果、血容量与卡牌强化

需求user-2026-10-23-card-upgrades-health-ui。用户要求：选择界面看见卡牌与遗物效果；血容量做成血条，护盾叠在血条上；移除牌由玩家选择；卡牌能够强化。作者/执行者均Codex，无DeepSeek调用。

## 决策信息

奖励、商店、营火学习、事件、宝箱、过层补给直接展示效果，卡牌列能量、形状、攻效、格挡、抽牌、治疗、能量、止血、穿甲及消耗等适用项。固定遗物显示实际效果；随机遗物说明抽取范围和全齐转金币。文字加大并自然换行，长内容允许滚动，不依赖悬停。

选择显示基础值，战斗按身体/遗物计算当前值。100%基础攻效对应每个命中格削1层，额外攻效按现有累计余数规则结算。穿甲跳过格子护甲。复用既有十项PNG，强化卡使用原卡图片。

## 一次强化

营火休息、强化、学习、移除择一。选择强化后从完整牌组点选一张，预览前后效果、确认后完成营火。每种54张基础卡都有对应变体，单张最多一次，名字带+并用绿色标识；同名牌分别处理。

Codex选择：攻击powerBonus+1，即基础攻效增加100个百分点；技能所有适用项目增加，格挡+3（原>=12时+5）、抽牌+1、治疗+4、能量+1。费用、形状、穿甲、消耗、止血均保持。直击100%→200%，举盾6→9，洞察2→3，专注能量1→2，缝合6→10。组合攻击仅增强攻效，组合技能增强其各项数值。数值为本项目设计，不宣称复刻杀戮尖塔。

奖励/legacy池在生成强化变体前冻结；奖励仍为原卡。牌组存base或base+，不改已有地图抽取顺序。强化定义在战斗、Auto、抽弃/消耗、溢出确认、牌组查看和存档中通用。

## 自由移除

营火、散页藏书室、商店均选择任意单张，可删除强化牌，至少保留5张。按牌组索引区分重复牌，点选可更换或取消，再点确认；确认前不收费、不改牌、不完成节点。商店20金币（罗盘折扣延用），确认后仅售出一次且仍在商店；营火/事件确认后离开。关闭弹层等同取消。此确认不影响攻击点格即出或超限弃牌须确认。

## 身体、血容量和盾徽

身体各部位生命合计继续显示。另有血容量0–100红色进度条、数值；低于65使用醒目颜色。血容量在战斗、地图概览和身体面板均可见。格挡为血条左侧叠放蓝色盾徽和数值，先抵扣受击伤害、下次己方回合开始时清空；没有把护盾加到血容量中。保留部位承伤/失血/要害失败机制。
