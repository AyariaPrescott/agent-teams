# 多敌人战斗与超限抽牌确认

需求user-2026-10-23-multi-enemy-draw。用户要求一场出现多个敌人，抽牌超限时让玩家选择丢弃、保留新抽到的牌；随后明确“弃牌需要确认”。以下敌人数、组合、缩放、版本与呈现均是Codex实施选择。

## 敌群

新旅途及进入新楼层使用routeVersion=5。每场1–3名敌人，各有6×4生命格、每格0–9层、独立护甲、力量、三段意图和首领狂怒。点击敌人选目标不耗能量；当前生命格、名称、护甲与预览对应所选敌人。选着攻击牌时也能换目标，形状放置仍点格即出；AUTO只为当前目标选落点，不替玩家选敌人。击败目标后自动转向第一个存活敌人。

结束回合时所有存活敌人按队列依次行动，共用并逐次消耗己方格挡。每次伤害重新按身体权重分配，若旅人失败则停止后续敌人动作。流血、血容量恢复和强化到期每整轮只处理一次。已死亡敌人不行动。只有所有敌人死亡才算胜利，金币、遗物与卡牌仍按节点一次结算，不因打倒一个随从提前领奖。

| 遭遇 | 新组合与数值 |
| --- | --- |
| 普通第一站 | 各层均1名，保留本体生命与攻击。 |
| 其余普通 | 通常2名；第3–5层有35%确定性概率为3名。2人分配原总生命60%/40%，3人45%/30%/25%，向下取整后余数补给最后一位。各自攻击与覆甲为原值60%（2人）/40%（3人），向上取整；仅领队保留力量增长。 |
| 精英 | 精英本体加1普通随从。本体不削弱；随从为其普通基础生命25%、攻击/覆甲45%，生命至少3，均向上取整，无力量增长。 |
| 第一层首领 | 单敌，原34/38/42生命和行动不变。 |
| 第2–3层首领 | 首领加1随从；随从基础生命30%、攻击/覆甲30%，不增长力量。 |
| 第4–5层首领 | 首领加2随从；每个随从基础生命20%、攻击/覆甲30%，不增长力量。 |

精英/首领本体保持上一轮逐层数值，随从只用当前层普通池，成员不重复。队伍由地图种子、节点ID、层数及变体派生，渲染/切换目标/读取存档不重抽、不推进战役随机状态。版本5沿用4的地图几何与内容池，额外增加组合元数据。

旧路线1–4保留单敌直至本层结束，旧战斗不凭空增加敌人；新开旅途或过层后进入5。此选择避免更新后当前难度突变。类型总数仍为55，队伍组合不计作新增敌种。

## 手牌整理必须确认

手牌上限仍为9，但抽牌请求不会因手牌已满而中止。已抽到的超额牌存入pendingDraw，原手牌不丢；抽牌堆空时按原规则重洗弃牌，若所有可抽牌都用尽才停止。回合抽牌、卡牌抽牌及开局遗物抽牌适用同一上限处理；抽牌增益不再因手牌上限而被裁掉。

弹层同时列出原手牌与待整理新牌，以唯一UID区分同名卡。点击卡牌只勾选/取消勾选，可以更换选择；已选达到超额张数才可点击“确认弃牌”。选择阶段不移动牌区，不额外花能量；触发抽牌的出牌或回合已经完整结算。确认时重新验证选中数量、唯一性和归属，再一次移动所选牌到弃牌堆，其余9张成为手牌。被弃的新牌和旧牌都可在之后正常洗回，不进入消耗区。例：原手牌9张又抽3张，会让玩家从12张中选择3张并确认。

待整理时不能出牌、医疗或结束回合，弹层不能被关闭绕过。勾选和确认分别自动保存；重新打开或导入存档会恢复新牌、原牌和未确认勾选，继续等待确认。抽牌和敌方整轮动作先完整结算保存，再显示动画/整理，不可靠刷新跳过。

## 存档与展示

JSON升级v4，继续沿用原本地存储键。battle.enemies记录每名敌人的cells、armor、maxHp、strength和intentIndex；targetIndex选择目标。全局能量/回合/出牌数/伤害小数余量保持共享。五个唯一牌区为hand/draw/discard/exhaust/pendingDraw，overflowSelection是尚未确认的勾选UID。选择只是牌区引用，不算第六牌区。

恢复重建预期队伍，验证成员数及各自上限、护甲、目标、整组胜负状态；五区必须完整且不重复地覆盖完整牌组。待整理只允许在playing且手牌9张时出现，选中必须唯一、属于手牌或待整理区、不超过超额数。v1–v3旧存档迁移为一个成员、目标0、空待整理区及空勾选；保留此前五层历史、旧图和战斗。v2/v3不重发战利品，v1保留既有一次迁移规则；迁移备份后存为v4。

桌面显示所有敌人画像/生命/意图，所选目标有框；手机紧凑排列并收起重复大目标图，生命格仍是当前敌人的棋盘。超限选择弹层使用桌面三列、手机两列，确认按钮保持可见。复用既有十项PNG并保留加载失败回退，没有新增图片或依赖。
