# 余烬回廊 · 五层旅途

本地原创卡牌爬塔网页，无运行依赖、账号或远程服务。打开 **余烬回廊.html** 游玩桌面版；将 **余烬回廊-手机版.html** 传到手机，用支持本地HTML脚本的浏览器打开。两个文件均内嵌全部代码、样式与十项PNG，可离线使用。

也可运行 node preview-server.cjs，电脑本地打开 http://127.0.0.1:4173/ 或 http://127.0.0.1:4173/mobile.html 。服务仅监听电脑本机。使用dist入口时须保留五个共享脚本、样式和完整assets目录；手机版另需mobile.css与mobile.js。

## 五层与内容

| 层 | 主题 | 首领生命 |
| --- | --- | --- |
| 1 | 残火之径 | 34 / 38 / 42，三位首领中随机一位 |
| 2 | 潮汐书库 | 60，溺海典藏者 |
| 3 | 铜炉工坊 | 82，百锤熔炉 |
| 4 | 碎镜天台 | 108，千面星后 |
| 5 | 群星熔心 | 144，永夜之心 |

新旅途每层12站47个候选节点，有七类节点、四种地图走向和真实分叉汇合；一局沿连接选择一条12站路线。后层的生命、攻击、护甲及狂怒更强；第一层保留较低难度，普通生命10–18、精英22–28。

共 **54种基础卡牌（每张可强化一次）、55种敌人（36普通/12精英/7首领）、28件遗物、24类双选事件**。新卡每层解锁6张、新遗物3件；高层战斗三选一保证一张本层新卡。营火可休息、强化单张卡牌、学习本层技艺或自由选择移除任意一张牌；高层商店还可再生缺失部位。精英与首领自动掉落一件本层已解锁且未拥有的遗物，池满改给45金币；宝箱可选遗物或随楼层增加的金币。

前四层首领胜利后选择进攻、防护或再生补给，修复存活部位60%、全部止血、补满血容量、获得35金币和一张下一层卡牌；再生补给另修复一支缺失部位树。牌组、金币、遗物和剩余伤势跨层延续。**击败第五层首领才完成整段旅途。** 主题、完整数值、卡牌及遗物清单见[五层说明](docs/FIVE-FLOORS.md)。

## 多敌与抽牌整理

新旅途和下一层可出现1–3名敌人，生命格、护甲、力量与意图各自独立。点击敌人选择目标，攻击形状放置在该目标的生命格上；切换不消耗能量，击败后自动转向存活敌人。结束回合时所有存活敌人依次行动，全部击败才发放一次战斗奖励。首层第一站和首领仍单敌；普通敌群分摊原总生命预算，随从伤害缩减。[详细机制](docs/MULTI-ENEMY-DRAW.md)。

手牌上限9张，继续抽到的牌会保留在待整理区。弹层同时列出原手牌和新牌，先勾选超额数量，可取消或更换，再点击 **确认弃牌**，所选牌才进入弃牌堆；未确认前不能出牌、医疗或结束回合。新牌不会被默认放弃，刷新后恢复待整理区与未确认选择。

旧路线1–4和已有战斗保留单敌；新开旅途或进入下一层使用路线5。v1–v4旧档可以导入为v5，保留已有敌人，不额外补发v2–v4战利品。

## 战斗与医疗

敌人生命是6×4正方形格子，每格最多9层、每层1生命，用数字及九色图例表示。选攻击牌后图案以鼠标或触点居中，点格即出；R/滚轮旋转、Shift+R反向、右键/Esc取消，方向键移动、Enter攻击。AUTO（A键）免除放置，点攻击牌自动选位置；数字键1–9出牌，E结束回合。高层卡牌可覆盖更大图案或一格削多层，按实际能力计算。

己方独立部位生命与8项能力。伤势、疼痛、失血、缺失会影响攻击、格挡、能量、抽牌与承伤。包扎无限次，每次1能量，修复存活部位并止血；包扎不能再生。强化剂默认每场1次，有炼金试管为2次，持续当前及后续共3个玩家回合。营火、事件、治疗卡、遗物及过层补给也能恢复身体。

手机竖屏使用中央可滚动战斗、横向手牌、固定操作栏和底部身体/路线/牌组/存档入口；横屏分栏。地图可滚动并定位下一站，弹层适配触屏与安全区。[手机说明](docs/MOBILE.md)。

## 自动存档与旧档

每次完整动作、奖励及过层选择后自动保存，存档菜单支持JSON导出、校验预览后导入及导出替换前备份。格式为v5，记录当前楼层、已过层路线/首领/补给、随机状态、身体、牌组、遗物及战斗。继续沿用旧存储键自动发现v1–v4。

v1/v2旧档视为第一层，v3/v4保留现有楼层；保留原地图、当前敌人、身体和牌组；固定旧抽取池，避免扩充内容后重建漂移。旧第一层已经通关时可直接选择补给前往第二层，v2不重发奖励。v1继续执行此前的降难度与一次遗物补发，然后备份并保存为v5。详见[存档说明](docs/FLOOR-SAVE.md)。

换设备、网址、端口或本地文件地址时请先导出，再在新入口导入。相同站点两个页面可能共用本地存储，切换时刷新目标页，避免同时游玩覆盖。存储失败会提示，仍可导出；不提供云同步。

## 美术、文件与审计

十项既有本地PNG包含废墟、纸张、角色、房间/敌人/卡牌图集；本轮用明确图片别名与各层色调复用，不代表每个新敌人都有独立画像。关键贴图使用实际img，加载失败保留回退。[美术清单](docs/ART-DIRECTION.md)。

balance.js定义内容；body.js处理身体；floor.js管理五层、节点和存档；game.js处理战斗及共享界面；art.js声明图片；mobile.js只处理触屏展示。tools/build-standalone.ps1默认合并两版离线HTML，不运行游戏。

[逐文件审计](docs/CHANGE-AUDIT.md)区分用户要求、Codex选择及实际执行者。全部项目修改进入PR，凭据、快照和私密审计只留本机。此次代码与文档均由Codex编写，未调用DeepSeek、未新增图片。

按用户要求，未运行游戏、语法检查、测试、浏览器自动化、设备模拟或试玩；仅审阅源码、差异、资源引用，并进行离线打包。实际难度、交互及视觉表现交由用户测试。

## 选牌、移除和强化

奖励、商店、营火、事件、宝箱和过层补给直接显示卡牌能量/形状/完整基础效果或遗物效果，无需悬停。战斗卡面显示身体与遗物修正后的当前值。

营火选择“强化卡牌”，点选单张、查看前后效果，再确认。强化后名字带“+”，永久保留并跨层生效；每张仅一次，同名牌分别强化。直击攻效100%→200%、举盾格挡6→9、洞察抽2→3、专注能量1→2；所有54种基础卡都有强化版，费用和攻击形状保持原样。

营火、藏书室及商店移除均让玩家自由选择一张牌，至少保留5张；确认前不删除、不收费、不消耗节点，可取消。待选牌和当前选择也自动保存。血容量用独立红条显示，身体合计生命另列；蓝色盾徽叠在血条左侧显示格挡。详见[强化与界面说明](docs/CARD-UPGRADES-UI.md)。
