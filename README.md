# 余烬回廊 · 石门守卫

这是一个原创、仅在本地运行的单关卡牌战斗原型。没有安装依赖、账号、服务端或外部资源请求。画面使用原创 SVG，游戏逻辑使用原生 JavaScript。

双击项目中的 **余烬回廊.html** 即可离线游玩；也可打开 `dist/index.html`，并保持该目录中的其余三个文件在原位。

玩法：每回合 3 能量、抽 5 张牌。点击卡牌，或用数字键 1–9 出牌；E 结束回合。观察守卫头顶的意图，安排攻击与格挡。灼烧在敌方行动前触发。胜利后可选择真实生效的遗物，再挑战同一关。

顶部提供音效开关、玩法说明和重试；底部可以查看抽牌堆、弃牌堆、完整牌组与战斗记录。音效默认关闭，仅由本机生成。

开发预览：`node preview-server.cjs`，然后打开 `http://127.0.0.1:4173`。验证：`node --test tests/game.test.cjs`。

当前测试由用户自行进行；本次推送没有重新运行游戏测试或浏览器自动化。仓库保留已有测试文件，供用户自行使用。

## 文件与贡献来源

- `余烬回廊.html`：包含全部样式、数据和逻辑，可独立离线打开。
- `dist/`：便于修改的 HTML、CSS、逻辑和基础平衡数据。
- `tests/`：已有的战斗逻辑测试。
- `preview-server.cjs`：仅监听本机的可选预览服务。
- [逐文件修改与贡献清单](docs/CHANGE-AUDIT.md)：列明 Codex 和 DeepSeek 的参与范围、用户要求、实施决定及本地审计关联。

主体代码、美术和交互由 Codex 实现；基础平衡数值由 DeepSeek 提议，Codex 复核采纳并执行文件写入。公开变更清单由 Codex 编写，DeepSeek 自己提交的原始审计独立保存在本机。仓库不包含凭据、私有审计原文或快照，也不在游戏中调用任何模型 API。
