# 余烬回廊 · 残火之径

原创、本地运行、无依赖的卡牌爬塔第一层。无需账号和远程服务。新版采用手绘暗黑幻想美术：生成的教堂废墟、旅人、普通敌人、精英、Boss和卡牌插画，配合羊皮纸路线与旧金铜界面。

双击 **余烬回廊.html** 可独立离线游玩，全部图片已内嵌。也可打开 `dist/index.html`，保持同目录的样式、五个脚本和 `assets/` 完整。若使用本地网站，运行 `node preview-server.cjs` 后打开 `http://127.0.0.1:4173/`。

## 一层旅途

路线共有八站、十八个节点，每次选择其中一条相连的路向上走。最后一站为灰冠门主，击败Boss后第一层通关。

| 节点 | 内容 |
| --- | --- |
| 战斗 | 战胜不同阶段的构装体，获得金币，三选一卡牌或跳过。 |
| 精英 | 更厚生命层、更强攻击，更多金币。 |
| 事件 | 选择恢复身体或获得50金币。 |
| 商店 | 购买治疗、横扫、坚守或穿甲遗物；每项每店限购一次。 |
| 营火 | 恢复身体，或学习十字斩。 |
| 宝箱 | 选择生命遗物、穿甲遗物或60金币。 |
| Boss | 灰冠门主，半血时攻击额外+3；攻击、覆甲、蓄势循环。 |

牌组、金币、遗物和身体伤势会延续到下一节点。完成一站时止血、少量修复存活部位并恢复血容量；营火、事件和商店可进一步治疗。缺失部位不能再生。每场战斗补充3次包扎、1次强化剂，战斗中的格挡和强化不会带入下一场。

新增奖励牌：十字斩（5格十字）、横扫（4格长线）、坚守（9点基础格挡）。残火之心增加躯干和心脏上限共10点，淬火刀锋使形状攻击穿甲；两件遗物可同时拥有。

## 战斗与窗口布局

头部显示层数进度、金币、路线和存档；主体随窗口缩放，底部固定手牌与结束回合。左侧保留关键能力和医疗入口，完整22部位及8项能力位于健康详情。小窗口压缩装饰，窄屏手牌过多时可在手牌区域横向滑动。

- 敌人生命是6×4方格，每格0–9层；每层1生命，颜色和数字表示层数，归零才碎裂。敌人总生命随遭遇不同而变化。
- 点击攻击牌，图案包围盒中心跟随鼠标吸附；点击棋盘立即出牌。边缘自动向内吸附，旋转保持瞄准中心。削层、破甲和伤害数字使用实际结算结果。
- R或滚轮旋转，Shift+R反向；方向键移动，Enter攻击；右键/Esc取消，1–9选牌，E结束回合。
- AUTO（A键）仅代选落点和旋转，点击攻击牌即可出牌，仍由你决定出牌和结束回合。
- 正常身体每回合3能量、抽5张牌。受伤与强化影响攻击、格挡、抽牌、能量、承伤及治疗；预览显示当前实际效果。
- 敌人攻击先消耗格挡，再按权重分布到部位。要害毁坏、意识低于30%、行动不高于15%或失血殆尽会结束旅途。
- 健康详情可选部位包扎或使用强化剂，各需1能量。强化持续当前及后续共3个玩家回合，能力可高于100%。

完整公式见 [身体与能力](docs/BODY-SYSTEM.md)，路线、奖励和存档规则见 [第一层与存档](docs/FLOOR-SAVE.md)。

## 自动保存与导入导出

成功出牌、医疗、敌方回合结算、进入/完成节点、购买和领取奖励后自动保存。重新打开同一个本地网址会恢复旅途、牌堆、身体伤势、敌人生命和随机状态。敌方回合先完整结算并保存，再播放动画；刷新不会撤销这次敌人行动。

点击顶部 **已自动保存 / 存档**：

- **导出当前存档**：下载JSON文件，可跨浏览器、网址或电脑转移。
- **导入存档**：选择JSON，校验后预览进度，确认替换；不会直接执行文件内容。
- **导出替换前备份**：导入或重开前保留最近一份本机备份，支持再次导入恢复。

浏览器本地存储属于当前浏览器与网址。`file://`、不同端口、`localhost` 与 `127.0.0.1` 的存储可能不同；需要迁移时先导出。浏览器禁用存储或空间不足时，顶部会提示无法自动保存，仍可导出。无效存档不会覆盖当前旅途。

## 文件、来源与验证范围

本轮重新生成7项PNG美术资产，其中卡牌图集包含10张独立插画；4个角色保留真实透明通道。普通敌人、精英和Boss使用不同贴图。界面样式整合为单一文件，统一场景、卡牌、地图、健康详情与存档弹窗；形状标记仍独立显示，生命层数字与颜色规则不变。图片以原始字节接入，没有添加远程运行请求。

[美术清单与完整生成提示词](docs/ART-DIRECTION.md)记录所有最终资产路径、尺寸、SHA-256和生成方式。图片由内置image_gen工具生成，Codex编写提示词、选择资产并接入界面；本轮未调用DeepSeek。

- `余烬回廊.html`：包含全部代码的独立离线文件。
- `dist/balance.js`：卡牌与基础数值；`dist/body.js`：部位和能力；`dist/floor.js`：路线与存档；`dist/game.js`：战斗和界面。
- `dist/art.js`、`dist/assets/`：图片路径清单、场景、地图、角色和卡牌图集。
- `preview-server.cjs`：仅监听本机的静态服务。
- `tests/`：已有战斗用例，本轮未改动或运行。
- [逐文件贡献与审计](docs/CHANGE-AUDIT.md)：区分用户要求、代理选择及实际执行者；私有快照和密钥只保存在本机，不提交仓库。

初始基础平衡曾由DeepSeek提议、Codex采纳；当前方格、堆叠、身体、居中交互及第一层/存档由Codex编写。上一轮DeepSeek复核因响应不完整未被采纳，本轮未新增DeepSeek调用。公开项目清单由Codex署名，不冒充DeepSeek自审计。

按用户要求，本轮未运行游戏测试、语法检查、浏览器自动化或试玩，只审阅源码、差异和提交内容。视觉适配、手感与平衡由用户实际游玩确认。
