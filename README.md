# 余烬回廊 · 石门守卫

这是一个原创、仅在本地运行的单关卡牌战斗原型。没有安装依赖、账号、服务端或外部资源请求。画面使用原创 SVG，游戏逻辑使用原生 JavaScript。

双击项目中的 **余烬回廊.html** 即可离线游玩；也可打开 `dist/index.html`，并保持该目录中的其余三个文件在原位。

敌人初始总生命为 **24**，分布在 **6×4** 的棋盘上。每个格子可堆叠 **1–9 层**，每层 1 点生命；数字与九种颜色共同表示剩余层数，0 层为空格。当前开局使用 1–3 层的分布，总生命等于所有格子的层数之和。

玩法：身体正常时每回合恢复3能量、抽5张牌；伤势与强化会改变这些数值。先点击攻击牌，或用数字键1–9选牌；图案以**鼠标为中心**在敌人生命棋盘吸附，**点击立即出牌，无需再次确认**。预览显示实际伤害，中心准星标记落点；点击格子之间的缝隙也可出牌。

图案按包围盒中心定位：奇数尺寸对齐格子中心，偶数尺寸对齐最近格线交点。靠近边缘自动向内吸附，保证完整形状留在棋盘内。旋转保持同一个瞄准中心；预览按帧跟随，点击使用当前坐标，避免快速移动时落到上一处位置。

打开棋盘下方的 **AUTO** 开关（快捷键 A），点击攻击牌就会自动选择落点和旋转并结算，免除手动放置。系统优先消除最多生命格，再考虑破甲；你仍决定出哪张牌、何时结束回合。Auto 默认关闭，开关本身不出牌，重试时保留本次会话的模式。

- 直击：3 格直线；重砸：5 格 L 形；招架：4 格 T 形并获得 3 格挡；余烬：2×2 方块。
- R或棋盘内滚轮旋转，Shift+R反向；方向键移动预览，Enter直接攻击，右键或Esc取消选牌，E结束回合。没有选攻击牌时，滚轮正常滚动页面。技能牌仍然直接打出。
- 形状不能越界；正常100%攻效时，每个覆盖的生命格削1层。受伤可能削层不足，强化可使格子一次损失多层，以预览小数字为准；0层才碎裂。覆盖空格不扣血，全空落点不会消耗卡牌。
- 红色预览边框表示削层，蓝色边框表示先破甲；预览保留层数原色与数字。守卫壁垒给3格覆甲，护甲不会恢复生命，也不代表额外生命层。
- 余烬是直接形状攻击，取消自动灼烧。胜利后可选“残火之心”（生命 +10）或“淬火刀锋”（攻击穿甲）重试。
- 攻击带有角色前冲、斩击轨迹、命中闪光、削层碎片及大号伤害数字；提示区分削去几层、击碎几格。破甲和格挡使用蓝色反馈，玩家受伤显示红色伤害。数字来自实际结算；遵循系统减少动态效果设置。

顶部提供音效开关、玩法说明和重试；底部可以查看抽牌堆、弃牌堆、完整牌组与战斗记录。音效默认关闭，仅由本机生成。

己方现在有22个独立身体部位和父子关系。敌人伤害先按行动/听觉换算、消耗格挡，再分成最多3段，按存活部位覆盖权重命中；命中部位、毁坏和连带缺失记入战斗记录并在人体图中闪光。身体条是部位HP之和；要害失效、意识低于30%、行动不高于15%或失血殆尽都会导致失败。

左侧健康面板显示意识、操作、行动、视觉、听觉、呼吸、血液循环、新陈代谢。它们实际影响攻击、格挡、抽牌、能量恢复、受击倍率、治疗与血容量恢复；疼痛和失血会进一步影响机能。点击“详情”可查看全部部位、命中权重与影响。

- **包扎**：选择受伤部位后消耗1能量，每局3次；按代谢修复部位、止血并恢复少量血容量，不能再生缺失部位。
- **强化**：消耗1能量，每局1次，持续当前及后续共3个玩家回合；正常身体的能力可超过100%，获得更多能量/抽牌、更强攻击/格挡和更低受击伤害。强化不能使已毁坏的身体机能恢复。
- [部位、能力与结算规则](docs/BODY-SYSTEM.md)列出本项目的完整公式和参考来源；这是卡牌战斗改编。

开发预览：`node preview-server.cjs`，然后打开 `http://127.0.0.1:4173`。验证：`node --test tests/game.test.cjs`。

当前测试由用户自行进行；本次推送没有重新运行游戏测试或浏览器自动化。仓库保留已有测试文件，供用户自行使用。
