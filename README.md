# 余烬回廊 · 残火之径

仅在本地运行的原创卡牌爬塔游戏，无运行依赖、账号或远程服务。双击 **余烬回廊.html** 可单文件离线游玩；也可运行 node preview-server.cjs 后打开 http://127.0.0.1:4173/。dist版本需要保留五个脚本、样式和整个assets目录。

## 扩展第一层

新旅途为**十二站、四十七节点，四种走向与变化的分叉汇合**：蜿蜒峡谷、双翼回廊、斜行长桥、收束深井。中间每站2–5节点，宽窄位置、节点坐标和实际连线由种子决定，每条路都能继续走到首领。房间类型、敌人、事件、商店与最终首领也随旅途变化。每次沿连接选择下一站，不能跳站或反复领奖。已有八站/固定十二站存档保留原连接关系；新开旅途使用变化的地图。

| 内容 | 当前数量 / 行为 |
| --- | --- |
| 卡牌 | 30张；形状攻击、穿甲、格挡、抽牌、能量、治疗、全部止血、消耗。 |
| 敌人 | 19种：12普通、4精英、3首领；有不同生命分布、意图与形象组合。 |
| 遗物 | 16件；改变开局资源、攻击、格挡、每回合能量/抽牌、恢复、金币及商店价格。 |
| 事件 | 12类，每类2个不同选择，可治疗、赚钱、学牌、精简牌组、交换或获得遗物。 |
| 商店 | 每店4张卡、1件遗物、治疗和移除直击；每项限购一次。 |
| 营火 / 宝箱 | 休息、学习或精简；宝箱从2件未拥有的遗物中选1件，也可选择55金币。 |

第一层普通敌人生命降到10–18、精英22–28、Boss34–42，攻击也较旧版温和。**击败精英或Boss自动获得一件未拥有的遗物**，结算页面显示名称和实际效果，随后保存；全部16件都拥有时转为45金币。点击战斗左下遗物按钮或地图的遗物入口查看收藏。

## 战斗和医疗

敌人生命仍是6×4方格，每格最多9层，每层1生命。选攻击牌后，图案以鼠标居中吸附，点击立即打出；R/滚轮旋转、Shift+R反向，方向键移动、Enter攻击，右键/Esc取消。AUTO（A键）只代选落点，出牌与结束回合仍由你决定。数字键1–9选牌，E结束回合。

旅人有22个身体部位、8项能力。受伤、疼痛、失血、缺失部位会影响攻击、格挡、能量、抽牌、承伤和恢复；遗物与卡牌还会增加实际效果。健康详情可查看部位与治疗。

- **包扎次数无限，每次仍花1能量**。修复存活部位并止血；缺失部位只能处理残端，不能再生。没有需要治疗的伤处时不可使用。
- 强化剂每场默认1次，炼金试管增加至2次；每次1能量，持续当前及后续共3个玩家回合。
- 完成节点后，存活部位修复上限5%（向上取整），全部止血、血容量+10。治疗卡可按代谢修复最重的存活伤处，回春还可全部止血。
- 要害毁坏、意识低于30%、行动不高于15%或失血殆尽仍会结束旅途。

规则见[身体与能力](docs/BODY-SYSTEM.md)与[扩展内容](docs/CONTENT-EXPANSION.md)。

## 贴图和场景

本地美术包括教堂废墟、羊皮纸地图、角色、原十卡图集，以及新增六房间、八敌人和二十卡图集。营火、商店、宝箱、事件、精英与Boss有对应画面；普通战斗也会使用废墟或泉林场景。

图片路径从art.js所在地址解析；卡面、路线纸张、角色、房间和敌人图集全部使用实际图片元素，图集通过明确的尺寸与偏移裁切。加载敌人图集时保留原角色，完成后切换；失败显示页脚入口并回退。新卡图集失败时使用基础插画，基础插画也缺失时保留形状徽标。地图画布按容器尺寸适配；独立HTML已内嵌全部10项PNG，无需旁边的assets目录。修改后刷新页面以加载新版，完整说明见[贴图与地图形状](docs/TEXTURES-MAP-SHAPES.md)。

生成方式、原始提示词、尺寸与哈希见[美术清单](docs/ART-DIRECTION.md)。图片由内置image_gen生成，Codex负责提示词、选择、接入；本轮未调用DeepSeek。

## 自动存档与迁移

动作完整结算后自动保存，顶部存档入口可导出JSON、校验预览后导入，并导出最近一次替换前备份。当前数据版本为2，继续沿用原存储键以发现已有v1进度。

v1迁移保留旧路线、身体与牌堆；当前敌人按剩余比例降血量，已碎裂格不会复活，力量减半，解除包扎次数限制。旧存档处在精英胜利或Boss通关结算时补发一次遗物，然后保存为v2，避免反复补发。导入始终先完整校验，不直接覆盖实例或执行文件内容。

浏览器与网址决定本地存储位置。不同端口、localhost、127.0.0.1和文件地址可能分别保存，迁移时使用导出/导入。存储失败会显示状态，仍可导出。详见[存档说明](docs/FLOOR-SAVE.md)。

## 文件与审阅范围

dist/balance.js定义内容，body.js处理身体，floor.js管理旅途/存档，game.js处理战斗和界面，art.js声明本地资源。tools/build-standalone.ps1仅打包源码与图片到独立HTML，不启动游戏或测试。

[逐文件贡献与审计](docs/CHANGE-AUDIT.md)区分用户要求、代理选择与实际执行者。私有快照、凭据、生成器原始输出位置只留在本机，所有本轮项目改动进入PR。

按用户要求，没有运行游戏测试、语法检查、浏览器自动化或试玩。只查看生成图片/元数据、审阅源码、资源引用和提交差异。既有测试文件本轮未改动；实际难度、手感和视觉适配交由用户试玩确认。
