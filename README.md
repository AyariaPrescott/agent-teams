# 余烬回廊 · 石门守卫

这是一个原创、仅在本地运行的单关卡牌战斗原型。没有安装依赖、账号、服务端或外部资源请求。画面使用原创 SVG，游戏逻辑使用原生 JavaScript。

双击项目中的 **余烬回廊.html** 即可离线游玩；也可打开 `dist/index.html`，并保持该目录中的其余三个文件在原位。

敌人生命已从 48 点降低为 **24 格（6×4）**，每个亮方格表示 1 点生命。

玩法：每回合 3 能量、抽 5 张牌。先点击攻击牌，或用数字键 1–9 选牌；再点击敌人生命棋盘，形状以该格为左上角，**点击立即出牌，无需再次确认**。鼠标悬停时可先查看落点。

打开棋盘下方的 **AUTO** 开关（快捷键 A），点击攻击牌就会自动选择落点和旋转并结算，免除手动放置。系统优先消除最多生命格，再考虑破甲；你仍决定出哪张牌、何时结束回合。Auto 默认关闭，开关本身不出牌，重试时保留本次会话的模式。

- 直击：3 格直线；重砸：5 格 L 形；招架：4 格 T 形并获得 3 格挡；余烬：2×2 方块。
- R 旋转，方向键移动预览，Enter 在预览处直接攻击，Esc 取消选牌，E 结束回合。技能牌仍然直接打出。
- 形状不能越界；允许覆盖已经打空的位置，但只有覆盖的尚存生命格会扣血。全空落点不会消耗卡牌。
- 红色预览表示将移除的生命格；蓝色表示将先去掉护甲。守卫壁垒给 3 格生命覆甲，护甲不会恢复生命。
- 余烬是直接形状攻击，取消自动灼烧。胜利后可选“残火之心”（生命 +10）或“淬火刀锋”（攻击穿甲）重试。
- 攻击带有角色前冲、斩击轨迹、命中闪光、生命格碎裂及大号伤害数字；破甲和格挡使用蓝色反馈，玩家受伤显示红色伤害。数字来自实际结算；遵循系统减少动态效果设置。

顶部提供音效开关、玩法说明和重试；底部可以查看抽牌堆、弃牌堆、完整牌组与战斗记录。音效默认关闭，仅由本机生成。

开发预览：`node preview-server.cjs`，然后打开 `http://127.0.0.1:4173`。验证：`node --test tests/game.test.cjs`。

当前测试由用户自行进行；本次推送没有重新运行游戏测试或浏览器自动化。仓库保留已有测试文件，供用户自行使用。

## 文件与贡献来源

- `余烬回廊.html`：包含全部样式、数据和逻辑，可独立离线打开。
- `dist/`：便于修改的 HTML、CSS、逻辑和基础平衡数据。
- `tests/`：已有的战斗逻辑测试。
- `preview-server.cjs`：仅监听本机的可选预览服务。
- [逐文件修改与贡献清单](docs/CHANGE-AUDIT.md)：列明 Codex 和 DeepSeek 的参与范围、用户要求、实施决定及本地审计关联。

主体代码、美术和交互由 Codex 实现；初始版基础平衡数值由 DeepSeek 提议，Codex 复核采纳并执行文件写入。当前方格生命、形状攻击、24 格生命和护甲规则均由 Codex 根据用户新要求重新设计，本次没有新增 DeepSeek 调用。公开变更清单由 Codex 编写，DeepSeek 自己提交的原始审计独立保存在本机。仓库不包含凭据、私有审计原文或快照，也不在游戏中调用任何模型 API。
