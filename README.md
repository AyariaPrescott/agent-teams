# 余烬回廊 · 五层旅途

本地原创卡牌爬塔网页，无运行依赖、账号或远程服务。打开 **余烬回廊.html** 游玩桌面版；将 **余烬回廊-手机版.html** 传到手机，用支持本地HTML脚本的浏览器打开。两个文件均内嵌全部代码、样式与十项PNG，可离线使用。

也可运行 node preview-server.cjs，电脑本地打开 http://127.0.0.1:4173/ 或 http://127.0.0.1:4173/mobile.html 。服务仅监听电脑本机。使用dist入口时须保留八个共享脚本、样式和完整assets目录；手机版另需mobile.css与mobile.js。

新旅途采用四向树海地图，节点数随种子和四种非矩形轮廓变化，可上下左右探索与回走；每层有首领、分支、补给与观测台。移动受行动力限制，步行按经过格数扣步，可用有限次数的折跃索或滑翔翼跨越节点。旧档保留当前层的12站/8站路线，到下一层切换新地图。后层的生命、攻击、护甲及狂怒更强；第一层保留较低难度，普通生命10–18、精英22–28。

共 **54种基础卡牌（每张可强化一次）、55种敌人（36普通/12精英/7首领）、28件遗物、24类双选事件**。新卡每层解锁6张、新遗物3件；高层战斗三选一保证一张本层新卡。营火可休息、强化单张卡牌、学习本层技艺或自由选择移除任意一张牌；高层商店还可再生缺失部位。精英与首领自动掉落一件本层已解锁且未拥有的遗物，池满改给45金币；宝箱可选遗物或随楼层增加的金币。

前四层首领胜利后选择进攻、防护或再生补给，修复存活部位60%、全部止血、补满血容量、获得35金币和一张下一层卡牌；再生补给另修复一支缺失部位树。牌组、金币、遗物和剩余伤势跨层延续。**击败第五层首领才完成整段旅途。** 主题、完整数值、卡牌及遗物清单见[五层说明](docs/FIVE-FLOORS.md)。

## 多敌与抽牌整理

新旅途和下一层可出现1–3名敌人，生命格、护甲、力量与意图各自独立。点击敌人选择目标，攻击形状放置在该目标的生命格上；切换不消耗能量，击败后自动转向存活敌人。结束回合时所有存活敌人依次行动，全部击败才发放一次战斗奖励。首层第一站和首领仍单敌；普通敌群分摊原总生命预算，随从伤害缩减。[详细机制](docs/MULTI-ENEMY-DRAW.md)。

手牌上限9张，继续抽到的牌会保留在待整理区。弹层同时列出原手牌和新牌，先勾选超额数量，可取消或更换，再点击 **确认弃牌**，所选牌才进入弃牌堆；未确认前不能出牌、医疗或结束回合。新牌不会被默认放弃，刷新后恢复待整理区与未确认选择。

旧路线1–4保留单敌，5保留原敌群，6保留状态遭遇；新旅途或下一层使用路线7的四向探索，继续有敌方状态攻击。v1–v7旧档可导入为v8，保留本层地图和已有敌人，不重发原战利品。

## 战斗与医疗

敌人生命是6×4正方形格子，每格最多9层、每层1生命，用数字及九色图例表示。选攻击牌后图案以鼠标或触点居中，点格即出；R/滚轮旋转、Shift+R反向、右键/Esc取消，方向键移动、Enter攻击。AUTO（A键）免除放置，点攻击牌自动选位置；数字键1–9出牌，E结束回合。高层卡牌可覆盖更大图案或一格削多层，按实际能力计算。

己方独立部位生命与8项能力。伤势、疼痛、失血、缺失会影响攻击、格挡、能量、抽牌与承伤。包扎无限次，每次1能量，修复存活部位并止血；包扎不能再生。强化剂默认每场1次，有炼金试管为2次，持续当前及后续共3个玩家回合。营火、事件、治疗卡、遗物及过层补给也能恢复身体。

手机竖屏使用中央可滚动战斗、横向手牌、固定操作栏和底部身体/路线/牌组/存档入口；横屏分栏。地图可滚动并定位下一站，弹层适配触屏与安全区。[手机说明](docs/MOBILE.md)。

## 自动存档与旧档

每次完整动作、奖励及过层选择后自动保存，存档菜单支持JSON导出、校验预览后导入及导出替换前备份。格式为v8，记录当前楼层、已过层路线/首领/补给、随机状态、身体、牌组、遗物及战斗。继续沿用旧存储键自动发现v1–v7。

v1/v2旧档视为第一层，v3–v7保留现有楼层；保留原地图、当前敌人、身体和牌组；固定旧抽取池，避免扩充内容后重建漂移。旧第一层已经通关时可直接选择补给前往第二层，v2不重发奖励。v1继续执行此前的降难度与一次遗物补发，然后备份并保存为v8。详见[存档说明](docs/FLOOR-SAVE.md)。

换设备、网址、端口或本地文件地址时请先导出，再在新入口导入。相同站点两个页面可能共用本地存储，切换时刷新目标页，避免同时游玩覆盖。存储失败会提示，仍可导出；不提供云同步。

## 选牌、移除和强化

奖励、商店、营火、事件、宝箱和过层补给直接显示卡牌能量/形状/完整基础效果或遗物效果，无需悬停。战斗卡面显示身体与遗物修正后的当前值。

营火选择“强化卡牌”，点选单张、查看前后效果，再确认。强化后名字带“+”，永久保留并跨层生效；每张仅一次，同名牌分别强化。直击攻效100%→200%、举盾格挡6→9、洞察抽2→3、专注能量1→2；所有54种基础卡都有强化版，费用和攻击形状保持原样。

营火、藏书室及商店移除均让玩家自由选择一张牌，至少保留5张；确认前不删除、不收费、不消耗节点，可取消。待选牌和当前选择也自动保存。血容量用独立红条显示，身体合计生命另列；蓝色盾徽叠在血条左侧显示格挡。详见[强化与界面说明](docs/CARD-UPGRADES-UI.md)。

## 五种负面状态

双方可叠加灼烧、出血、破裂、沉沦、震颤，显示“威力×次数”，点徽记查看触发规则。余烬施加灼烧、直击施加破裂、招架积累震颤；重砸/断岩等可爆发震颤造成失衡。状态在命中后触发旧效果、再附加新效果，每张牌只触发一次。沉沦削弱下一次攻击，失衡打断行动；这些是本作对原作触发关系的改编。

状态说明同步选牌/强化，包扎清战术出血，强化剂解除沉沦/震颤；伤口流血仍独立处理。敌群独立计数，状态杀死敌人后不会再行动，全灭才领奖。新旅途和下一层用路线7，旧档当前层地图与敌人规则保留；旧卡获得当前状态效果。v8自动保存双方状态、地图移动与永久科技，兼容v1–v7。[完整规则和卡牌清单](docs/COMBAT-STATUSES.md)。

## 遗物栏与永久科技

顶部横排展示本局遗物，按获得顺序排列，每件配有独立原创图标。桌面悬停或聚焦显示效果，点击看详情；手机点图标即可查看，遗物较多时横向滑动。点左侧「遗物」打开图鉴。

右侧「科技」进入余火传承：锋刃、庇护、远行三分支共9项。击败第1至5层首领分别获得 **1 / 1 / 2 / 2 / 3点**，同一旅途相同层只记一次，新旅途可再次赚取。各分支按前置逐阶解锁，费用1/2/3点，要求曾通第1/2/4层。

**点数与已解锁科技重开保留，新解锁能力下次新旅途生效。** 加成涵盖攻击、状态威力、能量、包扎、格挡、金币、开局抽牌及传家罗盘。本局科技快照跨层持续，不因读档或开面板重领开局资源。

永久记录独立本地保存，同时包含在v8完整旅途的导出文件中。确认导入会合并通层记录及已解锁科技，重复导入不重复发点；分开消费的备份合并会重新核算余额，超出消费先由后续收入补足。旧档依据合法通层历史补领一次科技点，重开后使用新解锁加成。[全部效果和存档边界](docs/RELICS-TECH-TREE.md)。清理浏览器数据前或换入口/设备前请先导出；仍由用户测试游戏。
## 四向树海与有限行动力

新地图参考黑流树海的平面探索方式，使用本作原创SVG节点图案。点节点先预览路线，再确认移动；四向小径可以回走，完成地点变为空地，不能重复进店、触发事件、治疗或领奖。靠近节点揭雾，观测台揭示2格内内容。

五层初始行动力 **14 / 13 / 12 / 11 / 10步**。徒步每经过一格扣1步，途中不能越过未完成内容；折跃索同轴2–3格、滑翔翼曼哈顿3格内，各消耗1步及1次装置，初始每层2次/1次。应急补给一次增加4步及1次折跃索。

0步时可迎战追猎，逐波增强；胜利确认返回后恢复至4步，不发金币、卡牌、遗物或科技点。正常节点精英与首领仍掉遗物。桌面地图旁、手机地图下方显示移动预览与确认；支持拖动浏览和定位旅人。自动存档记录位置、步数、迷雾、装置及追猎战斗；旧档本层保留，下一层或新旅途启用新图。[地图机制、参考来源与原创图案](docs/TREE-SEA-MAP.md)。
